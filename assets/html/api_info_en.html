Forecast data can be accessed as JSON files via a static API hosted on GitHub Pages. Each file contains 'metadata' (forecast context) and 'data' (time-series values). National aggregates and per-TSO breakdowns are available. Files are ~40-220 KB each.

Example: fetch and parse a forecast file with Python:


import requests, pandas as pd
base_url = (
    "https://smnfrs.github.io/"
    "energy_market_analysis/"
    "data/DE/api/forecasts/"
)
file_name = "national_load.json"
response = requests.get(f"{base_url}{file_name}")
response.raise_for_status()
json_data = response.json()
metadata = json_data['metadata']
df = pd.DataFrame.from_records(json_data['data'], index=['index'])
df.set_index('datetime', inplace=True)
df.index = pd.to_datetime(df.index, utc=True)
print(df.head())

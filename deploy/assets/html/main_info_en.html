Week-ahead forecasts for electricity generation and load in the German/Luxembourg (DE/LU) bidding zone, produced from Open-Meteo weather data using gradient-boosted tree models (LightGBM, XGBoost) with physics-informed features.

Why this exists: SMARD publishes official TSO forecasts at ~18:00 CET — six hours after the 12:00 CET day-ahead auction. These forecasts use the same weather inputs but are available days in advance, enabling earlier price modelling and trading decisions.

What's Forecasted

  • Wind Offshore — 50Hertz, TenneT
  • Wind Onshore — 50Hertz, TenneT, Amprion, TransnetBW
  • Solar — 50Hertz, TenneT, Amprion, TransnetBW
  • Load — 50Hertz, TenneT, Amprion, TransnetBW
  • National aggregates — DE/LU totals including Luxembourg (Creos TSO)

Data Sources

  • Weather: Open-Meteo — 30+ curated locations near generation assets
  • Actuals: SMARD v2 — per-TSO generation and load (no API key required)

How It Works

  • Physics-informed features: wind power density, air density, wind shear, solar angle, heating/cooling degree days
  • Multi-step recursive hourly forecasting over a 168-hour (7-day) horizon
  • MAPIE conformal prediction intervals
  • Hyperparameter tuning via Optuna with honest rolling cross-validation
  • Fully automated: GitHub Actions collects data, runs inference, and publishes daily
